riffpad beta

Your AI coding agents, in your pocket.

Riffpad is now in beta — a tiny local daemon that bridges Claude Code, Codex and Kimi Code to your phone. Watch long tasks run, approve file changes, and send a new instruction without going back to the desk.

■ Watch long tasks run Session status, tool calls and file changes stream to your phone in real time.
■ Approve from anywhere When the agent waits for permission, one tap on your phone keeps it moving.
■ Local-first, end-to-end encrypted Code and API keys stay on your computer. The relay forwards ciphertext and keeps none of it.
