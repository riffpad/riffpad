# Riffpad Landing

The Riffpad marketing landing page: Next.js 14 (App Router) + TypeScript + Tailwind CSS, statically exported to `out/`, with EN/ZH locales and light/dark themes.

## Development

```bash
pnpm install
pnpm --filter landing dev
pnpm --filter landing build
pnpm --filter landing lint
```

The build output lives in `apps/landing/out/` and can be handed to any static host (Vercel, Cloudflare Pages, etc.).

## Layout

```
app/          # Next.js App Router pages and global styles
components/   # Header / Hero / Terminal mockup / sections
lib/          # EN/ZH copy dictionaries
public/       # robots.txt / sitemap.xml
```

## Design references

- `DESIGN.md` is Riffpad's own **Console-Mobile** design spec: terminal console × phone remote.
- Keep the restrained terminal character (monospace fonts, console surfaces, a few `//` and `●` glyphs), but deliberately stay clear of opencode's manpage style: use the brand amber, square-cornered cards, and bento grids; avoid `:~$` / `~/` / `[button]` ornaments in the chrome.
- Dark theme, EN/ZH bilingual, and CJK sans-serif fallbacks are all part of the spec.
- Design-system decisions are recorded in `design-system/riffpad/` at the repo root (generated by the ui-ux-pro-max skill).
- Typography uses the Geist Mono variable font (OFL License, see `app/fonts/GeistMono-OFL.txt`).
